# Pista 2. Bug en `useCart.ts`, pruebas locales y variables en la nube

Para cumplir `CA-5.1` y `CA-5.2`, abre `frontend/src/hooks/useCart.ts` y revisa el cálculo de `totalCents` dentro de `useMemo`. Agrega al carrito tres unidades de un mismo producto y mira el total. ¿Cuánto debería costar llevar tres? Compara con lo que suma el `reduce` y mantén los montos en centavos enteros hasta formatearlos con `formatQuetzales`.

Corre `npm run typecheck`, `npm run build` y `npm test` dentro de `frontend/` (o ejecuta `make check STEP=5` desde la raíz) para verificar que el hook y las tres vistas pasen `vitest`.

Para `CA-5.3`, recuerda que Neon ofrece dos URLs distintas. Usa la URL directa (sin `-pooler`) al ejecutar migraciones desde tu terminal, y configura la URL pooled en Vercel junto con `NEON_AUTH_JWKS_URL` y `VITE_NEON_AUTH_URL`.

Para seguir el checklist paso a paso del deploy, abre [la pista 3](3.md).
