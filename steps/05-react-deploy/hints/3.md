# Pista 3. Checklist exacto para Neon, Vercel y `make check-prod`

Sigue estos pasos después de corregir `totalCents` en `frontend/src/hooks/useCart.ts` y confirmar que `make check STEP=5` pasa en local.

1. En Neon Console abre tu proyecto, activa **Neon Auth**, agrega tu dominio `https://<tu-app>.vercel.app` en **Trusted Domains** y copia el **Auth URL** junto con el **JWKS URL** (`.../.well-known/jwks.json`).
2. Aplica las migraciones desde tu terminal usando la URL directa de Neon (sin `-pooler`).
```bash
DIRECT_DATABASE_URL="<tu-url-directa>" make migrate
```
3. En Vercel, dentro de **Project Settings -> Environment Variables**, agrega tres variables para el entorno de Production.
   - `DATABASE_URL` con la URL **pooled** de Neon.
   - `NEON_AUTH_JWKS_URL` con el JWKS URL de Neon Auth.
   - `VITE_NEON_AUTH_URL` con el Auth URL base de Neon Auth.
4. Haz deploy en Vercel, registra tu URL pública en `deploy.json` (`{"app_url": "https://tu-app.vercel.app"}`) y verifica tanto en local como en producción.
```bash
make check STEP=5
make check-prod
```
