# Pista 3 — Paso 5

Checklist exacto para desplegar en Vercel y Neon.

1. En Neon Console abre tu proyecto, activa **Neon Auth**, agrega tu dominio `https://<tu-app>.vercel.app` en **Trusted Domains** y copia el **Auth URL** y el **JWKS URL** (`.../.well-known/jwks.json`).
2. Corre las migraciones desde tu terminal usando la URL directa (sin `-pooler`):
   `DIRECT_DATABASE_URL="<tu-url-directa>" make migrate`
3. En Vercel (Project Settings -> Environment Variables) agrega estas tres variables en Production:
   - `DATABASE_URL` (la URL **pooled** de Neon)
   - `NEON_AUTH_JWKS_URL` (el JWKS URL de Neon Auth)
   - `VITE_NEON_AUTH_URL` (el Auth URL base de Neon Auth)
4. Haz deploy, escribe tu URL pública en `deploy.json` (`{"app_url": "https://<tu-app>.vercel.app"}`) y valida todo con:

```bash
make check STEP=5
make check-prod
```

Para el criterio extendido (`CA-5.4`) corre `make check STEP=5 EXTRA=1`.
