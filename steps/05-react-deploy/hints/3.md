# Pista 3. Lista de verificación antes de correr `make check` y hacer deploy

Ejecuta estos comandos dentro de `frontend/` para detectar errores de tipos y accesibilidad antes de subir cambios.

```bash
npm run typecheck
npm test
npm run build
```

Verifica tres puntos frecuentes que suelen fallar en `CA-5.1` a `CA-5.4`.

1. Revisa `tsconfig.json` para confirmar `"strict": true` y elimina cualquier `any` explícito o implícito usando interfaces para `Product`, `CartItem` y `Order`.
2. Al enviar el checkout, deshabilita el botón mientras `isSubmitting` sea `true` y genera una `Idempotency-Key` con `crypto.randomUUID()` por intento de compra para evitar órdenes duplicadas al hacer doble clic.
3. Antes de correr `make check STEP=5 EXTRA=1`, verifica en la terminal que tu URL en producción responde sano en `/health`.

```bash
curl -fsS "$DEPLOY_API_URL/health"
```
