# Pista 3. Esqueletos del aviso de envío gratis

En `useCart.ts`, lo que falta es la diferencia entre el umbral y el total. Si el total ya pasó el umbral, la diferencia sería negativa, y `Math.max` la deja en cero.

```ts
const freeShippingRemainingCents = Math.max(0, ?);
```

En `FreeShippingNotice.tsx`, el componente devuelve un solo elemento con `role="status"` y elige el texto según la prop.

```tsx
export function FreeShippingNotice({ remainingCents }: FreeShippingNoticeProps) {
  return (
    <p role="status">
      {remainingCents > 0 ? `Te faltan ${formatQuetzales(?)} para envío gratis` : '?'}
    </p>
  );
}
```

Después importa el componente en `CatalogView.tsx` y ponlo en la barra del carrito, junto a `cart-total`, con `remainingCents={cart.freeShippingRemainingCents}`. Corre `make check STEP=5`.
