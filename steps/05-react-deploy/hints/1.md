# Pista 1. Estado derivado en React y lectura de TypeScript

En React, la interfaz refleja el estado actual. Conviene distinguir qué datos vienen del backend (catálogo e historial de órdenes), qué datos viven en el cliente (`items` en `useCart.ts`) y qué valores conviene derivar al vuelo con `useMemo` (como `totalCents` y `itemCount`) para mantener una sola fuente de verdad.

Si vienes de Python, lee primero [example/python_vs_typescript.md](../example/python_vs_typescript.md) y recorre `frontend/src/lib/api.ts`, `frontend/src/lib/auth.ts` y `frontend/src/views/CatalogView.tsx` para seguir el recorrido completo de una petición HTTP desde el navegador.

Para revisar el bug de `useCart.ts` y la configuración de producción, abre [la pista 2](2.md).
