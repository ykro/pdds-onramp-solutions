# Pista 1. Mira cuándo cambia el total

Agrega una unidad de un producto y mira el total; agrega otra del mismo y vuelve a mirar. ¿Cambió? El total y lo que falta para el envío gratis se calculan a partir de `items`; no se guardan aparte.

Para revisar el bug de `useCart.ts` y el aviso de envío gratis, abre [la pista 2](2.md).
