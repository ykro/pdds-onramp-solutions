# Pista 3. Implementación exacta en las tres capas

En `backend/tiendita/services/store_service.py`, asegura el filtro por usuario en `get_my_orders` (`CA-4.1`) y agrega `get_product` (`CA-4.2`).

```python
def get_my_orders(self, user_id: str) -> list[dict[str, Any]]:
    orders = self._repo.list_orders_for_user(user_id)
    return [o for o in orders if o["user_id"] == user_id]

def get_product(self, sku: str) -> dict[str, Any]:
    product = self._repo.get_product_by_sku(sku)
    if product is None:
        raise KeyError(f"Unknown SKU: {sku}")
    return product
```

En `backend/tiendita/repositories/orders_repo.py`, declara `get_product_by_sku(self, sku: str)` consultando `products` con parámetro `%s` y devolviendo el diccionario o `None` si no existe.

En `backend/tiendita/api/app.py`, registra la ruta `GET /api/products/{sku}` (`CA-4.2` y `CA-4.3`).

```python
@app.get("/api/products/{sku}")
def get_product(
    sku: str,
    service: StoreService = Depends(get_store_service),
) -> dict[str, Any]:
    try:
        return service.get_product(sku)
    except KeyError as exc:
        raise HTTPException(status_code=404, detail=str(exc)) from exc
```
