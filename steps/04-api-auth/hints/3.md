Patrón base para `verify_jwt_token` en `backend/tiendita/api/auth.py` (la dependencia `get_current_user_id` ya la llama por ti).

```python
client = get_jwk_client(jwks_url)
signing_key = client.get_signing_key_from_jwt(token)
decode_kwargs = {
    "algorithms": ALLOWED_ALGORITHMS,
    "options": {"require": ["sub", "exp"]},
}
if issuer:
    decode_kwargs["issuer"] = issuer
if audience:
    decode_kwargs["audience"] = audience
else:
    decode_kwargs["options"]["verify_aud"] = False

return dict(jwt.decode(token, signing_key.key, **decode_kwargs))
```

En `backend/tiendita/api/app.py`, los endpoints `POST /api/orders`, `GET /api/orders/mine` y `PATCH /api/products/{sku}/stock` delegan en `StoreService` y traducen `KeyError` a `404`, `OutOfStockError` a `409`, `ForbiddenError` a `403` y `ValueError` a `400`.
