# Pista 3. Esqueletos de las tres capas

En `store_service.py`, `get_my_orders` recibe el `user_id` del token. El servicio es donde vive la regla de autorización, así que no confíes en que el repositorio ya filtró. Termina la comprensión de lista.

```python
def get_my_orders(self, user_id: str) -> list[dict[str, Any]]:
    orders = self._repo.list_orders_for_user(user_id)
    return [o for o in orders if ?]
```

Para el endpoint nuevo, cada capa hace una sola cosa. Estas son las firmas; los cuerpos te tocan a ti.

```python
# repositories/orders_repo.py: consulta products con %s y devuelve dict o None
def get_product_by_sku(self, sku: str) -> dict[str, Any] | None: ...

# services/store_service.py: si el repo devuelve None, lanza KeyError
def get_product(self, sku: str) -> dict[str, Any]: ...

# api/app.py: traduce KeyError a HTTPException con el código que corresponde
@app.get("/api/products/{sku}")
def get_product(sku: str, service: StoreService = Depends(get_store_service)) -> dict[str, Any]: ...
```
