# Pista 3. Dependencias de FastAPI, errores y pruebas aisladas

Conecta tus capas mediante `Depends` y usa `app.dependency_overrides` en `pytest` para inyectar repositorios en memoria y usuarios autenticados de prueba.

```python
from fastapi import Depends, HTTPException, status

def get_current_user(credentials=Depends(bearer_scheme)) -> AuthUser:
    if credentials is None:
        raise HTTPException(status_code=status.HTTP_401_UNAUTHORIZED, detail="Token ausente")
    return verify_jwt_token(credentials.credentials)
```
