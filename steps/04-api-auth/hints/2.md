# Pista 2 — Paso 4

La validación de JWT en `backend/tiendita/api/auth.py` exige tres comprobaciones juntas en `verify_jwt_token`.

1. Fijar explícitamente los algoritmos asimétricos permitidos (`ALLOWED_ALGORITHMS = ["RS256", "EdDSA"]`).
2. Obtener la llave pública que corresponde al `kid` del token mediante `get_jwk_client(jwks_url).get_signing_key_from_jwt(token)`.
3. Validar `exp`, `iss` y `aud` (si se configuró audiencia) y exigir el claim `sub`.

Para el aislamiento entre usuarios (`CA-4.4`), la regla vive en `StoreService.get_my_orders(user_id)` filtrando los pedidos cuyo `user_id` coincida con el usuario autenticado.
