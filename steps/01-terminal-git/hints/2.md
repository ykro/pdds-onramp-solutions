# Pista 2. Estructura del script y manejo del conflicto

Para el script de reporte, arranca siempre con `set -euo pipefail` en las primeras líneas. Esa cabecera hace que el script se detenga de inmediato si falta un archivo, si una variable queda vacía o si falla un comando dentro de un pipe.

Usa `jq` para extraer los campos que pide el reporte (`jq -r` elimina las comillas en cadenas de texto). Comprueba el ejemplo funcional en [example/sample_report.sh](../example/sample_report.sh) y adapta los filtros a lo que piden los criterios `CA-1.1`.

Para el conflicto de merge, ejecuta `git status` para ver los archivos marcados como `both modified`. Abre el archivo, lee ambos bloques entre `<<<<<<<` y `>>>>>>>`, combina los cambios válidos y borra por completo los marcadores antes de correr `git add` y `git commit`.
