# Pista 3. Secuencia paso a paso en terminal

Ejecuta estos comandos desde la raíz del repositorio para aislar los bugs y confirmar cada criterio.

1. Inspecciona `data/access.log` y verifica los conteos esperados con `wc` y `awk`.
```bash
head -n 5 data/access.log
wc -l < data/access.log
awk '$4 ~ /^5[0-9][0-9]$/ { c++ } END { print c + 0 }' data/access.log
awk '{ print $3 }' data/access.log | sort | uniq -c | sort -nr | head -n 3
```

2. Crea una rama nueva antes de guardar cambios.
```bash
git checkout -b fix/step-1-log-report
```

3. Corrige el código de salida `1` y el patrón `^5[0-9][0-9]$` en `scripts/log_report.sh`, asigna permiso de ejecución y prueba ambos casos.
```bash
chmod +x scripts/log_report.sh
./scripts/log_report.sh data/access.log
./scripts/log_report.sh data/no-existe.log; echo "exit=$?"
```

4. Confirma que la salida imprime exactamente `total_requests=`, `errors_5xx=` y `top_endpoints=` con el formato `ruta:conteo` separado por espacios.

5. Completa `docs/stories/001-order-history.md` con Como / Quiero / Para y al menos dos criterios Dado / Cuando / Entonces, revisa tu diff contra [examples/code-review.md](../../../examples/code-review.md) y valida todo con `make check STEP=1`.
