# Pista 3. Guía directa paso a paso

Sigue esta secuencia en la terminal desde la raíz del repositorio.

1. Verifica `jq` y prueba el filtro sobre `data/products.json`.
```bash
jq '. | length' data/products.json
jq -r '.[] | "\(.id)\t\(.name)\t\(.price_cents)"' data/products.json | head -n 5
```

2. Crea una rama nueva antes de editar cualquier archivo.
```bash
git checkout -b feat/step-1-report
```

3. Asegura permisos de ejecución en tu script y pruébalo directamente.
```bash
chmod +x scripts/report.sh
./scripts/report.sh data/products.json
echo $?
```

4. Al resolver el conflicto de merge, busca marcadores restantes antes de confirmar el commit.
```bash
git grep -n '<<<<<<<\|=======\|>>>>>>>' || echo "Sin marcadores pendientes"
```

5. Completa `docs/stories/001-order-history.md` contrastando cada punto contra los 5 criterios de `examples/historia-y-pr.md`, haz commits pequeños por archivo lógico y ejecuta `make check STEP=1`.
