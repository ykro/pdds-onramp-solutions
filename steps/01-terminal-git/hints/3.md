# Pista 3. Guía directa paso a paso

Sigue esta secuencia en la terminal desde la raíz del repositorio.

1. Inspecciona `data/access.log` y prueba los conteos con `wc` y `awk`.
```bash
head -n 5 data/access.log
wc -l < data/access.log
awk '$4 ~ /^5[0-9][0-9]$/ { c++ } END { print c + 0 }' data/access.log
awk '{ print $3 }' data/access.log | sort | uniq -c | sort -nr | head -n 3
```

2. Crea una rama nueva antes de editar cualquier archivo.
```bash
git checkout -b feat/step-1-log-report
```

3. Da permisos de ejecución a `scripts/log_report.sh` y comprueba ambos casos, archivo válido y archivo inexistente.
```bash
chmod +x scripts/log_report.sh
./scripts/log_report.sh data/access.log
./scripts/log_report.sh data/no-existe.log; echo "exit=$?"
```

4. Confirma que la salida imprime exactamente las tres claves `total_requests=`, `errors_5xx=` y `top_endpoints=` en formato `ruta:conteo` separado por espacios.

5. Completa `docs/stories/001-order-history.md` contra `examples/historia-y-pr.md` y, si haces el alcance extendido, documenta `docs/postmortems/001-log-incident.md` siguiendo `examples/postmortem.md`. Al terminar, corre `make check STEP=1`.
