# Pista 1. Empieza por entender los datos y el flujo

Antes de escribir código o tocar ramas, inspecciona qué contiene `data/products.json` directamente desde la terminal. Un buen script de shell transforma texto estructurado con herramientas pequeñas como `jq`, `sort` y `wc` en vez de parsear JSON a mano con `grep`.

Respecto a Git, piensa en cada commit como una unidad lógica que otro desarrollador puede revisar y revertir por separado. Si un conflicto de merge aparece, Git te está pidiendo una decisión editorial sobre qué líneas deben coexistir.

Si necesitas refrescar cómo moverte por carpetas o usar pipes, revisa [example/intro-terminal.md](../example/intro-terminal.md). Si quieres avanzar un poco más, abre [la pista 2](2.md).
