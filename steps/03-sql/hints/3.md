# Pista 3. Patrón transaccional e índices concretos

Estructura el checkout dentro de una sola transacción (`with conn.transaction():` en `psycopg` 3).

```sql
-- 1. Bloquea los productos en orden ascendente por id
SELECT id, price_cents, stock
FROM products
WHERE id = ANY(%(product_ids)s)
ORDER BY id
FOR UPDATE;

-- 2. Verifica en Python que cada producto tiene stock >= quantity
-- 3. Descuenta stock de forma segura
UPDATE products
SET stock = stock - %(qty)s
WHERE id = %(product_id)s AND stock >= %(qty)s;

-- 4. Inserta la orden y sus order_items dentro de la misma transacción
```

Para acelerar el historial de órdenes de un usuario ordenado por fecha descendente (`CA-3.6`), crea un índice compuesto que coincida con el filtro y el orden.

```sql
CREATE INDEX IF NOT EXISTS idx_orders_user_created
ON orders (user_id, created_at DESC, id DESC);
```
