# Pista 3. Patrón transaccional e índices concretos

Estructura `orders_repo.place_order()` dentro de una sola transacción (`with conn.transaction():` en `psycopg` 3).

```sql
-- 1. Bloquea la fila del producto antes de validar stock
SELECT id, price_cents, stock
FROM products
WHERE sku = %s
FOR UPDATE;

-- 2. Si stock < quantity, lanza OutOfStockError y la transacción hace rollback
-- 3. Descuenta el inventario con seguridad
UPDATE products
SET stock = stock - %s
WHERE id = %s;

-- 4. Inserta la orden en orders y su detalle en order_items dentro de la misma transacción
```

Para acelerar las búsquedas por producto en `order_items` (`CA-3.6`), agrega el índice en `db/migrations/003_indexes.sql`.

```sql
CREATE INDEX IF NOT EXISTS idx_order_items_product_id
ON order_items (product_id);
```

Levanta PostgreSQL con `make db-up`, revisa el plan en `psql` con `EXPLAIN ANALYZE` y corre `make check STEP=3` (o `make check STEP=3 EXTRA=1`).
