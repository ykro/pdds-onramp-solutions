# Pista 1. Esquema relacional, consultas parametrizadas y filtros en SQL

En una aplicación real, el esquema de PostgreSQL protege la integridad de los datos incluso si un servicio comete un error. Abre `db/migrations/001_init.sql` y `diagrams/db-schema.svg` para ver cómo se conectan `products`, `orders` y `order_items` mediante llaves foráneas y constraints `CHECK`.

Antes de escribir tus consultas de reporte, levanta PostgreSQL con `make db-up` y revisa [example/guided_joins_and_groupby.sql](../example/guided_joins_and_groupby.sql). Fíjate también en qué ocurre cuando un filtro de estado como `cancelled` se omite en un reporte o cuando una consulta en Python interpola entrada del usuario dentro de un f-string.

Para revisar los detalles de cada archivo del paso, abre [la pista 2](2.md).
