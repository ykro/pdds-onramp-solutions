# Pista 1. Mira qué SQL llega a PostgreSQL

¿Qué texto recibe `cur.execute` cuando el SKU es `' OR '1'='1`? Este comando arma el mismo f-string y lo imprime.

```bash
uv run python -c "sku = \"' OR '1'='1\"; print(f\"... WHERE p.sku = '{sku}'\")"
```
