# Pista 1. Deja que la base de datos proteja sus propias invariantes

Muchas reglas de integridad pertenecen al esquema de PostgreSQL y a las transacciones, más allá de las validaciones en Python. Si una columna `stock` tiene `CHECK (stock >= 0)`, la base de datos rechazará cualquier intento de dejar inventario negativo incluso si dos procesos llegan al mismo tiempo.

Antes de preocuparte por bloqueos, practica unir tablas y agrupar resultados en [example/guided_joins_and_groupby.sql](../example/guided_joins_and_groupby.sql). Después piensa en qué ocurre cuando dos transacciones leen `stock = 1` en el mismo milisegundo.

Para ver cómo coordinar esos accesos sin corrupción, abre [la pista 2](2.md).
