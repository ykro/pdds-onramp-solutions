# Pista 3. Guía directa para enteros, pruebas y búsqueda

Usa aritmética entera para porcentajes sin pasar por `float`. Por ejemplo, para aplicar un porcentaje `rate_bps` (en puntos básicos, donde `1200` equivale a 12%) con redondeo al centavo más cercano, suma la mitad del divisor antes de dividir.

```python
def apply_percent_cents(amount_cents: int, percent: int) -> int:
    return (amount_cents * percent + 50) // 100
```

Asegúrate de cubrir estos casos mínimos en tus pruebas de `pytest`.

- Un carrito con varios ítems y cantidades mayores a 1.
- Un ítem con cantidad `0` o negativa que levanta `ValueError`.
- Una compra que pide más unidades que el stock disponible.
- Un cupón fijo cuyo monto supera el subtotal, verificando que el total final sea `0` y nunca negativo.
- Un cupón expirado o por debajo del mínimo de compra.
- La misma compra con los ítems en distinto orden para confirmar el mismo total.

Para `CA-2.6`, mantén una lista paralela de precios ordenados y usa `bisect.bisect_left` y `bisect.bisect_right` para recortar el subarreglo exacto sin recorrer toda la lista. Ejecuta `make check STEP=2` para validar todo contra las versiones con bugs plantados.
